Regelmodule

Module sind versionierte JSON-Daten. Sie können zusätzliche Spezies, Laufbahnen und Erschaffungsmodi bereitstellen, führen aber keinen Code aus.

Modulformat

Jedes Paket enthält ein Manifest mit ID, Version und Schema-Version. Module können Spezies, Klassen/Laufbahnen, zusätzliche Charakterfelder und Erschaffungsregeln deklarieren. Die Kampagnenleitung kann freigegebene Versionen aktivieren; private Charaktere dürfen zusätzlich lokale oder persönliche Module verwenden.
